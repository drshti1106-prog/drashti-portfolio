# Drashti Panchal Portfolio

## Run it
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser.

No build tools are required. Google Fonts are loaded from the internet; the page still works if they are unavailable.

## Personalize before publishing
Search in `index.html` for:
- `YOUR_EMAIL@example.com` and replace it with your real email address.
- `YOUR_USERNAME` and replace it in your GitHub and LinkedIn links.
- The education, skill, and project descriptions. Keep only skills you genuinely use.
- Add a real project link or screenshot for each project card.

## Publish
You can upload these files to GitHub Pages, Netlify, or another static website host.
