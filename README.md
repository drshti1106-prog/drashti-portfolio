## Run it
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser.

No build tools are required. Google Fonts are loaded from the internet; the page still works if they are unavailable.

## Personalize before publishing
Search in `index.html` for:
- `YOUR_EMAIL@example.com` and replace it with your real email address.
- `YOUR_USERNAME` and replace it in your GitHub and LinkedIn links.
- The education, skill, and project descriptions. Keep only skills you genuinely use.
- Add a real project link or screenshot for each project card.

## Publish
You can upload these files to GitHub Pages, Netlify, or another static website host.

## 🖥️ Getting Started

Run the project locally in just a few steps.

### Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code (optional)
- Git (optional, for cloning the repository)

### Installation

*1. Clone the repository*

bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git


*2. Navigate to the project directory*

bash
cd YOUR_REPOSITORY


*3. Open the website*

Open index.html directly in your browser, or use the *Live Server* extension in Visual Studio Code.

That's it! No dependencies or build commands are required.

## 🌐 Deployment

This is a static website and can be deployed using *GitHub Pages, **Netlify, or **Vercel*.

### Deploy using GitHub Pages

1. Push your project files to a GitHub repository.
2. Open the repository and navigate to *Settings → Pages*.
3. Under the build and deployment section, select *Deploy from a branch*.
4. Choose your branch (usually main) and the root folder (/).
5. Click *Save* and wait for deployment.
6. Open the published URL displayed in the Pages settings.

Ensure that index.html, style.css, and script.js are included in the repository.
